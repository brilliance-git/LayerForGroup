# LayerForGroup

Home of **LayerLink**, a WoW Classic Era addon that combines every layer's LFG tool into one
board for the whole realm. The addon and its full docs are in [`LayerLink/`](LayerLink/README.md).

Install: copy the `LayerLink` folder into `World of Warcraft/_classic_era_/Interface/AddOns/`.

Tests: `cd LayerLink && lua5.1 tests/run.lua`
